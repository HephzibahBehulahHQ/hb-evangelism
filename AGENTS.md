# Evangelism division guidance

This repository represents the HB Evangelism division. [hb-AI-policy](https://github.com/HephzibahBehulahHQ/hb-AI-policy) governs agent work; [hb-design-system](https://github.com/HephzibahBehulahHQ/hb-design-system) governs visual standards. Read the README and `docs/content-guidance.md`.

Keep eBible applications, learning-content systems, product code, user data, deployments and product-specific integrations in their dedicated repositories. Preserve the division mission, faith identity and approved branding. Use branches and PRs; do not deploy or merge to `main` without authorization.
